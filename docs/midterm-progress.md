# 中期代码更新

本次整合已归档的RoadLab系统和实验工具，并补齐可移植配置、依赖、测试与复现文档。早期筛选、转换、UFLD工具和界面工作流继续保留。

正式系统包括四类目标入口、车道/手动选位、两种生成路线、语义保护、预测缓存与常驻CPU分析、任务记录、审核标框和COCO导出。审核逻辑明确区分辅助意见与项目成员确认。

独立研究保留六方向扩展和联合/逐位置生成比较。可展示个例及49组记录支持流程分析，尚未证明跨场景稳定性或下游检测增益。未采纳的保护V3和局部细化不覆盖正式流程。

代码更新修正了README命令位置、服务器固定路径、依赖不足、测试依赖旧服务器及审核测试分散的问题。新增跨目录启动、配置和实验图结构检查；当前本地CPU测试记录见[验证说明](validation.md)。

下一阶段按来源划分独立数据集，补齐成员标注与遮挡关系，再比较真实数据训练和加入合成数据训练的检测表现。LoRA训练材料不在本次发布范围。完整模型、环境、图库及学校报告也不进入代码历史。
