# 中期记录与评测口径

- 正式网页为四类入口。六方向扩展和逐位置方案是独立实验，没有增加为十类正式功能。
- `experiments/evidence/multi-object-results.json`归档49组最终结果，对应77次采样。126张输出包含解码及阶段合成，不是126次独立扩散任务。辅助标签不是成员真值或独立测试集成功率。
- 同源背景、位置与基础种子的联合/逐位置比较同时改变提示词和计算次数，属于工作流对照。石球个例从1个变为2个，部分水泥墩仍有重复。
- 缓存重复输入测试各3次，中位车道掩膜预处理用时5.1701秒与0.7374秒；输出遮罩哈希相同。这不是整条FLUX生成链路的耗时或通用加速比。
- 6组30步/50步开发对照未显示稳定整体真实感收益。V3保护和局部再细化未成为正式默认，记录保留于历史决定文件。
- 历史22项回归由19项原测试与3项审核门槛测试组成。当前发布的CPU检查应以本次运行记录为准；软件通过不代表图像质量验收。
- `sample37`原始清单的新模型为CLRerNet DLA34 EMA，与正式CLRNet R18接入不同。其2/3张空掩膜和3张缺少本车道双边界统计不能直接归给R18。
- 旧LaneDetect代理指标采用传统图像处理参考，不是独立人工车道真值。CODA目标框不等于车道标注。
- 未完成独立下游检测器的mAP增益验证。训练/测试应按原图哈希及同源序列划分，并完善既有目标与新增目标标注。
